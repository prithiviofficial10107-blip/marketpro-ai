# Asset Management System (Smart ERP + AI SQL Agent)

A professional, enterprise-grade Asset Management System built with a modern tech stack. Features an intelligent AI SQL Agent that understands your database, manages assets via natural language, and provides deep analytics.

## 🚀 Key Features
- **Smart Dashboard**: Real-time KPIs and interactive charts (Recharts).
- **AI SQL Agent**: ChatGPT-like interface powered by GPT-5 (via OpenRouter). Understands English and Tamil.
- **Enterprise Security**: JWT-based dual-token authentication (Access/Refresh) and RBAC.
- **Audit Trail**: Every critical action is logged for full accountability.
- **Modern UI**: Professional Dark Mode, Framer Motion animations, and ERPNext-style data tables.
- **Reports**: One-click PDF and Excel exports.

## 🛠️ Tech Stack
- **Frontend**: React (Vite), TailwindCSS, Framer Motion, Recharts.
- **Backend**: Flask (Python), SQLAlchemy, MySQL, Flask-JWT-Extended.
- **AI**: OpenRouter (GPT-5).
